# Security Policy

This is an experimental firmware build recipe, not a vendor-certified firmware.

- Do not commit passwords, subscriptions, VPN private keys, personal UBI dumps, Wi-Fi calibration data, or other secrets to this repository.
- Never hardcode a common root password in a publicly distributed image.
- Review GitHub Actions workflow and third-party feed changes before running privileged automation.
- Verify firmware SHA256 checksums and device partition layout before flashing.
- Please report suspected security issues privately to the repository maintainer through GitHub's private vulnerability reporting, if enabled; otherwise do not publish exploit details or private keys in issues.
